# CampusMate — College Companion App

CampusMate is a student productivity web application designed to help college students organise their academic life in one place.

## Features
- Student dashboard
- Daily class timetable
- Add, complete, and delete assignments
- Attendance tracking with a percentage indicator
- Quick notes with delete functionality
- Saves assignments, notes, and attendance in browser local storage
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start using the assignment manager, attendance tracker, and notes.

## Project Goal
This project demonstrates beginner-level frontend development, interactive user interfaces, and browser-based data persistence.

Created as a college student portfolio project.
